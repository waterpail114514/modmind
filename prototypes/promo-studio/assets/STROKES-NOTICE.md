# Stroke data attribution

Stroke medians in strokes.json are an extracted subset of hanzi-writer-data 2.0.1:
https://www.npmjs.com/package/hanzi-writer-data
https://github.com/chanind/hanzi-writer-data

The dataset derives from Make Me a Hanzi by Shaunak Kishore:
https://github.com/skishore/makemeahanzi

The upstream stroke graphics derive from Arphic fonts and are provided under the Arphic Public License. The upstream software is MIT licensed. Dataset use in this project is for assigning local system font pixels to independently animated stroke masks.
