# 皮肤工坊的上游依据

皮肤工坊遵循 [minecraft-pixel-skin](https://github.com/SuiSuiNian721/minecraft-pixel-skin) 公开说明的 Minecraft 64×64 RGBA、Slim/Classic 和 UV 像素检查约定。该仓库是 Codex Skill，不是 npm SDK；其仓库未提供明确的再分发许可证，因此本功能没有复制其脚本、模板、参考图或第三方渲染 bundle。ModMind 在本地实现了最小的 UV/透明度检查与编辑器，并保留来源链接供用户查阅。

皮肤工坊保存的是用户项目 `.modmind/skins/*.png` 与同名模型元数据，不会上传账号或自动下载游戏资源。通过工具返回的 `gameRuntimeVerified: false` 表示尚未在游戏内验证。
