# 工作台渲染与交互检查

## 已复现并修复

| 问题 | 修复 | 验证 |
| --- | --- | --- |
| 流式消息正文为空时，Virtuoso 报 Zero-sized element | 消息容器保留最小测量高度；用 flow-root 包含子元素外边距，防止高度漏算 | 空消息转正文、React StrictMode、控制台无错误 |
| 工作台面板很窄，但窗口很宽时仍使用桌面布局 | 工作台响应式规则改用容器宽度；同步调整消息宽度、标题与菜单定位 | 1440 像素窗口内的 320、390、480、760、1000 像素面板 |
| 八个附件横向撑出输入框、遮挡操作 | 附件换行并限制区域高度，发送按钮保持宽度 | 检查容器无横向溢出、发送按钮未被裁切 |
| Markdown 链接显示原始加粗/代码标记；代码块继承行内代码底色 | 用解析后的内联 token 渲染链接；代码块独立样式；图片限宽、表格局部滚动 | 富文本与转义单测、图片/长代码/表格、深浅主题 |
| 异常历史时间戳可能令消息渲染抛错 | 无效日期不渲染时间文字 | 无效时间戳正文正常显示 |
| 输入框固定两行，Shift+Enter 误发送 | 输入框随正文及宽度变化自适应，最高 200px；Shift+Enter 换行 | 增高、缩回、换行 |
| 部分弹层缺少 Escape、外部关闭和焦点管理 | 统一已有弹层关闭逻辑；键盘打开后进入内容，Escape 回到触发按钮；增加名称和展开状态 | 引擎、上下文面板键盘操作与外部点击；原有对话切换测试 |
| 阅读、选择文本或展开步骤时可能被底部跟随打断 | 指针阅读暂停跟随；显式回到最新内容后恢复；合并每帧滚动请求 | 展开步骤后追加内容位置不变、回到底部、尺寸变化 |
| Markdown 全局缓存保留多份流式全文快照 | 改为组件内只记忆当前内容 | 渲染回归；不保留 500 个旧全文快照 |

## 动画审查

| Before | After | Why |
| --- | --- | --- |
| 展开箭头 200ms ease，键盘同样等待 | 指针 160ms transform，复用 --ease-out；键盘立即响应 | 状态反馈更短，可连续反向打断；不动画正文高度 |
| 上下文编辑面板悬停出现，焦点停留时难关闭 | 点击/键盘显式展开，关闭立即生效 | 可编辑内容由明确交互控制，避免悬停闪现与 Escape 后重现 |
| 每次列表高度通知取消再申请滚动帧 | 每帧合并请求，暂停跟随时不申请 | 减少重复调度；降低滚动与阅读操作冲突 |

审查结论：本次改动通过。保留状态指示，沿用全局减少动态效果设置；不增加消息入场或正文高度动画。展开箭头属于轻量状态反馈，使用 CSS transform 与现有缓动变量。
