# 专业模式交互式新手教程（第一版）

只在专业模式运行。简洁模式不显示首次问答、教程遮罩、教程菜单或新增下载入口，不改变其侧栏规则。

首次进入专业模式询问使用经验：新手选择项目类型与第一个目标；老手跳过。经验选择不切换界面模式。所有起步目标都先引导安装对应项目的完整推荐组合，通过真实控件完成工具准备、项目创建和进入工具。下载步骤不会因为已有组件而省略，失败或安装尚未就绪时不会提前推进。

## 已接入路线

| 项目 | 首个目标 | 首项目标工具 | 最终入口 |
| --- | --- | --- | --- |
| Mod | 制作物品 | 物品与装备 | 物品与装备 |
| Mod | AI 实现玩法 | 内置模组工作台 | 工作台输入框 |
| 整合包 | 添加模组 | 模组列表与下载 | 模组下载 |
| 整合包 | 制作任务 | FTB 任务书 | FTB 任务书 |
| 服务端插件 | AI 制作指令 | 内置服务端插件工作台 | 工作台输入框 |
| 服务端插件 | 找到测试工具 | 游戏与服务端测试及依赖 | 服务端测试 |
| 光影 | 查看源码 | 光影工作台、光影源码 | 光影源码 |
| 光影 | 调整选项 | 光影工作台、光影选项 | 光影选项 |

表中的功能是最终打开的任务入口；实际准备范围为工作台加该项目的完整推荐组合，复用 `featureBundles` 清单。Mod 为物品、Mappings、关系、版本和测试 5 项；整合包为模组、内容、自动化、FTB 任务书、版本和测试 6 项；服务端插件为关系、版本和测试 3 项；光影为源码、选项、预览、验证和导出 5 项。所有任务共用同一项目组合，包括只使用 AI 的任务。

Mod、整合包和服务端插件工作台复用内置组件，光影工作台按实际状态引导下载。教程依次定位「推荐组合」、对应项目、「选择组合」与「安装所选」，复用商店批量安装、启用、更新和取消；`featureInstallPlan` 统计含依赖且去重的下载体积。已有组件不重复下载，有更新的组件随组合更新。官方组件沿用既有可信安装流程；本地导入仍保留来源与权限确认。

## 交互与恢复

- 黑色遮罩保留当前控件的可操作区域；提示框说明具体动作。所有推荐项及工作台都安装、启用、更新且界面已载入后，显示「整套推荐组合已就绪」，必须点击「准备好了，继续」才推进。重播且全部已安装时也会介绍入口并停留在此确认步骤。
- 创建资料逐字段指导，必填名称为空时不能继续。第一版指引 Java 项目；Mod 平台步骤要求选中 Java 版。
- 原生安装确认框保持原有权限与来源信息，在框内突出确认按钮。系统目录选择窗口由操作系统处理，教程说明选择位置并在返回后继续。
- 安装失败、版本不兼容、功能未发布、界面加载失败和创建失败均保留恢复入口。退出教程不取消已有安装、不删除项目；下载取消仍使用原有下载服务。
- 进度保存在 `modmind-onboarding:v1`。重开应用时可继续；恢复总是重新走完整推荐组合检查，不尝试恢复已经消失的表单。上次创建的项目仍为当前项目时，准备完成后直接回到工具，不重复创建；其他情况下重新准备创建流程，保留原有项目。
- 专业模式标题栏的问号按钮从头播放教程，「更多操作」仍提供继续或重开入口。简洁模式不显示问号，也完全不挂载教程。键盘 Escape 暂停；Tab 在当前控件与提示框之间移动，支持减少动态效果与主题变量。

## 实现选型

复用 Driver.js **1.9.0**（MIT）：https://github.com/nilbuild/driver.js 。使用其遮罩、目标定位、滚动跟随与焦点约束，React 管理业务步骤和恢复。它没有运行时依赖，适用于 Electron 的 Chromium 与现有 React 界面；主界面以外的原生系统窗口不在其定位范围内。版本锁定在 package-lock.json，保留上游许可声明。

教程代码与样式按需加载并随应用打包，本身不联网。下载组件仍需要网络；没有完整组合或下载条件时，教程保留检查与稍后继续入口，不能跳过组合进入创建步骤；暂停教程后仍可自行使用已就绪的内置工作台和本地项目功能。使用成熟库避免重新实现定位与焦点逻辑，项目判断和简短状态逻辑保持本地实现。后续升级需回归跨页面目标、原生安装弹窗和桌面窗口尺寸。

窗口验收使用真实桌面窗口的最小尺寸（当前主窗口为 1080×680）与常用桌面尺寸。脚本通过 Electron 调整窗口并读取实际内容区，不模拟手机视口。

这项交付是界面引导，不新增业务服务或 MCP 工具。安装、目录、创建与项目操作继续使用既有服务和权限链。
