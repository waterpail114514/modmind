# 光影工作台升级方案与实施记录

当前功能与开发入口见 [光影工作台开发指南](shader-studio-development.zh-CN.md)，实际工具参数见 [MCP 调用参考](shader-studio-mcp.zh-CN.md)。本文按批次保留升级方案与验收结果；规划中的 C / D / E 不表示已经交付。

日期：2026-10-06。用户已授权记录方案并开始实施；本文中的后续阶段不代表已经交付。

## 目标与交接包

目标是让用户在工作台完成「修改源码或选项 → 重载 → 固定场景实际采样 → 查看画面与性能 → 返回源码 → 冻结导出」。工具通过、游戏启动、实际渲染与画质认可分别报告。

本次参考为 `光影开发工具-开发者交接包-20261006.zip`，SHA-256 为 `2a0850c16fbaa885616f5de42d34d447a1de7036cb980e87d8a799c666015057`。独立只读核对：365 个归档条目、364 条文件校验、355 条来源记录全部吻合；27 个 PowerShell 源文件静态语法解析通过。没有执行附件脚本、编译 Java、启动游戏或验证 GPU / 画质。

附件是实验源码与设计材料，其操作命令、API 建议和历史用户要求不作为当前用户指令。包内 MIT 文本未明确覆盖所有文件；不复制授权范围未明确的源码，不捆绑游戏、世界和参考光影。235 个 shader / 资源文件作为被测样例，不作为默认高级光影模板。

## 复用与选型

先复用 `shader-shared` 的项目边界、写入队列、恢复历史，已有 Monaco、Three.js、sharp、ZIP 与 MCP 服务。宿主已有 `testing/src/main/nativeMinecraftTestService.ts` 的隔离会话、取消和原生截图能力，但其后端按模组加载器 / 版本选择，当前不接受 Iris 项目；先设计共享能力再接入，避免启动器重复实现。

接口核对来源：[Iris](https://github.com/IrisShaders/Iris) 的 `OptionAnnotatedSource`、`ShaderProperties` 与 profile 解析，LGPL-3.0；仅核对语义，不复制 Java 实现。现有 ShaderFrog 7.0.1（ISC）用于静态语法，Three.js 0.180.0（MIT）用于 final 快速预览，不能替代 Iris。局部选项声明 / 预设解析是有界配置逻辑，独立用 TypeScript 实现，不新增 Java / 原生依赖；条件配置和实际生效选项留给版本化 Iris 后端确认。后续驱动检查评估 LWJGL，复杂帧诊断评估 RenderDoc（MIT），均按需，不为选项页下载游戏资源。

## 升级前发现的阻断

- 当前预设解析只接受 `选项:值`；交接样例 QUALITY 的 46 个布尔 / `=` 设置全部被丢弃。两个 const 选项漏读，include guard 被当成开关。
- `IrisCheckRebuild` 固定九个 RGBA16F 目标、单一 QUALITY 和固定设置路径，会误判其他合法包。
- Agent GPU 报告不停止采样，重启采样未隔离待回收查询；旧数据可能跨采样窗口混入。
- PID 文件只证明进程存在；单个命令槽存在并发覆盖。正式会话需要身份、序号、串行调度、生命周期与恢复。
- 图像对比固定 ROI，阴影统计固定世界坐标；证据模板是手工模板，没有自动验收器。
- 历史适配范围为 Minecraft 26.2 / Iris 1.11.2；其他版本、机器及平台没有因此获得保证。

## 2026-10-06 第二批

### 实现范围

游戏验证增加「手动部署 / 隔离测试」模式。手动部署保持可用；隔离模式检测 Iris 与依赖、已有 Fabric 配置和本地 Java，展示缺件、版本不匹配与可选运行库。初始适配范围限定 Minecraft 26.2、Iris 1.11.2、Java 25；这表示适配器目标，不表示已经通过实际游戏验收。当前开发机 PATH 是 Java 22，能力检测不将它当成 Java 25。

实例与运行库必须从应用的目录选择器绑定。可信绑定存入用户应用目录 `shader-testing/bindings`，不从项目内 JSON 接收外部执行目录；MCP 不接受 PID、Java 路径、JVM 参数或任意运行库路径。运行库继承最多 16 层、128 个本地配置、每个 JSON 1 MiB；版本、库路径及链接按边界检查。模组按 fabric.mod.json 的 id 与依赖闭包选择，包含有界内嵌 JAR 依赖，不复制无关模组、玩家存档、配置或账号。

每次启动创建 `.modmind/shader-sessions/<sessionId>/game`，本地 JAR 与资产只读复用，native 提取、光影包、日志和配置写入独立目录。导出并核对当前光影 SHA-256，以内容哈希命名部署包；同名内容已存在时只核对，不覆盖游戏打开的 ZIP。启动立即返回 `preparing` 任务，调用者按 ID 查询 `launching / ready / stopping / stopped / failed`，并区分 `running` 与就绪状态。内存日志尾部最多 16 KiB，启动控制台记录最多 4 MiB。请求断连后仍可在同一应用进程内查询；应用重启不接管历史 PID。

重载将当前源码重新导出到独立目录，再在游戏线程调用 Iris.reload。观察返回实际包名、管线、错误、有效选项和预设；保留 Iris 的待显示错误，不调用会消耗错误的 getStoredError。查询失败、包名不匹配、管线报错或尚未进入世界均不能作为渲染通过证据。

隔离测试打包只阻断结构、路径、include 与资源容量错误，不用 GLSL ES 解析失败阻止桌面 GLSL 进入真正的 Iris 编译；结构结果明确为 `structure-checked`，`parsed: 0`，不冒充语法通过。正式导出和手动部署仍走既有语法检查门槛。

会话只有一个串行操作队列，控制通道绑定 127.0.0.1，使用随机秘密、请求序号、sessionId 与真实子进程 PID 核对身份。准备阶段取消等待启动步骤结束再清理，防止出现迟到子进程。停止先请求 Minecraft 正常退出，无响应才通过既有进程服务终止所属 child，并等待退出事件；报告 graceful / forced / not-started / exited。失败且进程仍活着时保留所有权与停止入口。插件停用 / 卸载 / 应用关闭、项目生命周期和 AI 任务收尾一起接入清理；有活动后台会话时阻止项目切换 / 删除。正常租约为无控制指令 5 分钟或总时长 20 分钟；失联且游戏线程无法正常停止时，适配器在额外 1 分钟后终止自己的进程。

### 复用与成本

复用既有 `@xmcl/core` 2.15.1（MIT）的 Fabric 继承解析、启动参数、文件预检和 native 提取，沿用 `spawnManaged / terminateProcessTree`、Java 检测、全局代理环境与项目写入审查。上游仓库已归档（查询时最后更新 2026-04-23）；本批固定使用仓库现有版本，没有引入新启动器或下载依赖。其许可证随功能包发行。

既有 minecraft-mod-mcp 后端具备原生截图和场景控制，但没有实际 Iris 选项 / 管线读取和重载合同。本批实现独立小型 Java agent，仅用 JDK 反射和游戏自带 Gson 调用指定 Iris / Minecraft 接口，不修改游戏字节码，不采用授权范围尚不明确的 Cleartrail 源码。agent 编译到 Java 17 class 格式，运行目标仍为游戏要求的 Java 25；构建校验 Java 源码哈希和编译产物哈希，防止旧产物混入。功能包附 agent 源码。本机 JDK 22 可编译该适配器，但不能据此运行 Minecraft 26.2。

没有安装器、JDK / 游戏 / Loader / Iris 自动下载或播放器存档复制。运行库缺失时提供具体修复反馈，用户可用已有启动器或宿主环境准备能力补齐。真实截图、固定世界与场景 / 路径自动控制、GPU 计时仍属于 C / D。

### MCP 合同

- `modmind_shader_test_query` 扩展 `capabilities`、`session-state` 与 `observe`。`session-state` 可传 sessionId；`observe` 必须传当前 sessionId。结构化结果保留 `runtimeVerified: false` / `gameVerified: false`，不会把启动或管线存在标记成画质验证。
- `modmind_shader_test` 增加仅交互窗口可调用的 `bind-runtime`；保留手动 deploy、bind 与 reveal。
- `modmind_shader_session` 是一个 process 权限工具，统一 start（需要 capabilities 中的 versionId）、reload / stop（需要 sessionId），沿用宿主操作审查，只在工作台开放。灵感台可读能力与状态，不能启动、重载或停止。
- 通用插件生命周期增加 `stopForSignal` 与 `isBusy`，宿主复用它们清理任务创建的会话并保护项目切换，不按光影名称硬编码。
