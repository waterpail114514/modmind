# 侧边栏编辑

入口：设置 → 通用 → 侧边栏 → 编辑侧边栏。

- 勾选入口控制显示；分类菜单可全部显示或隐藏。
- 入口和分类通过上下箭头调整顺序，主侧栏原有拖动排序继续可用。
- 入口旁的下拉框可移入其他分类，包括刚创建的空分类。
- 分类名平时显示为文字，点击才进入编辑，回车或失焦时保存，Esc 取消；空白名称和重名会提示修改。
- 删除分类后入口及显隐状态保留在“未分类”，不会删除任何功能或项目内容。未分类是有遗留入口时才出现的系统容器，不能删除。
- 支持撤销最近 20 次修改和恢复默认布局。空分类只在编辑器显示。
- 所有入口都可隐藏；窗口顶部“更多操作 → 打开设置”始终可用于恢复。

布局沿用现有侧栏的项目类型、Java/附加包类型和简洁/专业模式分区，不按单个项目保存。编辑器只列出该模式、项目与已启用插件当前支持的入口。临时不可用的插件或内容工具仍保留其分组、排序和显隐偏好，重新出现时恢复。

## 实现与选型

复用 React、Lucide、MoreActions、现有侧栏原生拖动和 localStorage。调研了 [dnd-kit](https://github.com/clauderic/dnd-kit)：MIT，提供 React 排序、跨容器拖动和键盘传感器；上游截至 2026-09-27 仍在维护。该库适合更复杂的拖放，但本次设置列表使用原生表单和可通过键盘操作的移动按钮，现有侧栏已有拖放实现，不引入新的传感器与拖动状态系统。本次新增运行时依赖为零，也不需要联网或下载资源。

`sidebarLayout.ts` 负责合并默认入口、旧布局迁移和编辑操作；设置编辑器与主侧栏共用它。布局使用一个版本化 localStorage 文档保存，写入成功后才更新界面，失败提供原位重试。读取损坏数据时暂用默认布局，不自动覆盖原数据。原 `modmind-sidebar-order:*` 的项目内排序、跨组分配及分类排序在首次读取时兼容迁入；保存新文档后以新文档为准。独立窗口通过 storage 事件同步。

这是个人界面布局偏好，不涉及项目内容操作，本次不新增工作台 MCP 工具。

## 验证

- `npx vitest run src/renderer/src/sidebarLayout.test.ts`：7 项数据迁移、排序、删除及临时不可用入口保留测试。
- `node scripts/sidebar-editor-smoke.mjs`：隔离配置的真实 Electron 页面，验证旧排序迁移、分类增删改名、入口显隐与移动、原侧栏拖动、重载保留、撤销、非法名称、保存失败与重试、损坏数据恢复、模式隔离、自定义分类独立窗口和跨窗口同步。
- 深浅主题分别在 1440、640、390 像素窗口操作并截图检查，覆盖按需改名和 Esc 后焦点恢复。
- 类型检查、主题检查和生产构建通过。界面测试使用新配置并阻断外部渲染资源访问；本功能只依赖本地偏好，不作其他在线服务的离线承诺。
