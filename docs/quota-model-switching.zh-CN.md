# ModMind 额度模型切换

2026-10-03：已接入多供应商同步 v2，完整连接集合、每台独立绑定、设置统一重置及刷新规则见 [v2 接入说明](model-routing-dual-credentials.zh-CN.md#v2-已接入)。下文记录旧单连接分组服务，继续用于未升级账号的兼容路径；v2 不再通过旧跨供应商 POST 切换免费套餐。

设置 → AI 与图像 → ModMind 使用家族列表、搜索和行内切换。推荐语直接描述模型定位与适用任务，仅对有明确替代的旧型号提供替代建议。思考强度、Fast 模式、上下文预算和当前自动线路收在高级设置。自定义 API 和本机 Codex 保留各自的配置方式。

## 目录与选路

`src/shared/quotaModels.ts` 保存 2026-10-02 使用授权账号实测的 17 个付费模型、供应商 2 的 8 个分组映射，以及可用免费套餐的 4 个模型。这份小型目录约数 KiB，不包含密钥。供应商 1 已废弃，不能成为目标；OpenRouter 登录用套餐没有额度，也不作为模型选项。目录排除专用审查、图片、语音与嵌入模型。

免费型号和含免费型号的家族用上标“免”标注。免费版与付费版使用独立 optionKey，不能仅按 model ID 判断哪个版本“使用中”。显式选免费版才切到 `trial:<ID>`，请求不带 group；返回付费版自动选择已开放付费分组，不静默降级到免费。

具体型号旁的“无缓存”依据当次 `/api/device/group` 返回的选中目标线路标签，仅在明确标注“无缓存”时出现；缺少说明表示未知，不表示支持缓存。能保留已核实的当前线路时优先使用当前标签，否则使用实际选路顺序的首个已开放分组标签。免费版单独读取免费套餐标签，不继承同家族或同 ID 付费版的缓存声明；家族不展示“无缓存”。当前实测仅 Kimi 与 Gemini 线路明确无缓存。MCP 目录通过同一服务返回可选的 `noCache:true` 字段。

推荐语的定位、价格与替代判断见 [模型选型核查](model-selection-research.zh-CN.md)，不按型号数字或 Flash 名称猜测强弱，不把官方单价当作账号实际扣费。

分组提示必须与 `/api/device/group` 当次返回的账号权限交集使用。先读取当前线路的 `/v1/models`（404 时兼容 `/v1/model`），能承载目标型号且计费版本匹配时保留当前线路；否则选择已开放且映射支持该型号的分组或免费套餐。当前 `/models` 失败不会阻断其他路由的发现；选路依据成功读取的 `/group` 和内置映射，在切换后仍须核实目标型号。完全断网时不能切换。

工作台、灵感台与启动页旧模型列表改为跨线路目录，选择型号也接入同一个切换服务；不能只修改会话型号再让执行时因当前线路缺少型号而失败。免费版的明确选择在设置页进行，旧紧凑列表保留当前免费型号，但不隐式引入新的免费选择。未知型号可从当前线路列表发现；未访问过的新线路和新型号之间的映射仍需更新快照，或由上游增加只读全量目录。

目录缓存最多保存一个账号、512 个当线路型号，60 秒失效；凭据和账号变化清空缓存。刷新失败保留内置文案与旧快照并标记状态，禁止把离线快照当作当前可用证明。首次离线无需下载目录，不影响本地项目工作。

## 切换与恢复

`QuotaModelRouting` 是界面、远程控制和 MCP 共用的服务。跨线前用当前模型 Key 建立独立 routingToken，通过 Electron safeStorage 加密保存后才发送切换；提前持久化目标型号及分组，用于应用退出或响应不明确后的恢复。正常请求带 expectedAccount/expectedGroup，串行执行，不向 renderer 或 MCP 返回 Key/token。

切换响应中的最新 baseUrl、apiKey、余额先保存，再回读分组并刷新目标模型列表；仅当 exact model ID 存在时保存模型偏好，思考强度按新模型重置为自动，Fast 模式保持原值。旧的模型扫描响应不能覆盖新配置。

账号凭据同时保存 account/group/node，以便识别免费计费范围和重启恢复。免费 baseUrl 已含 `/api/trial/v1`，不得重复追加 `/v1`。免费套餐不要求付费余额、不请求付费用量，也不向免费 Key 同步付费 Fast 设置；原付费 Fast 偏好保留，切回付费时继续使用。

网络超时、502 或部分失败后先用独立会话回读凭据，不假定仍在旧线路，也不盲目再次签发 Key。目标已完成且型号可查时可以完成本次提交；否则保留恢复记录，显示错误和“恢复连接”。尚未核实的切换会阻止新的额度任务启动。429 遵循服务端 Retry-After，其他失败有短暂冷却。会话过期或被撤销时尝试用仍有效的模型 Key 更新；重新授权清理旧会话记录。

当前客户端有额度 AI 任务运行时拒绝切换，不迁移正在运行的请求。全局账号路由可能影响其他客户端；服务端条件更新只防止覆盖它们的新线路选择，无法代表跨客户端任务占用锁。

## 复用与依赖

复用现有设备授权、HTTP、加密存储、模型能力注册表、偏好存储和配置修订屏障，未增加依赖。已比较仓库使用的 models.dev（MIT）和 LiteLLM 元数据：两者可补充通用模型能力，但无法处理 ModMind 账号级分组、凭据结算和独立切换会话，因此不引入整套代理框架。元数据已有的版本与许可证记录保持原来源。

## 工作台 MCP

- `modmind_list_quota_models`：读取全账号模型目录、文案、当前型号、线路和可切换状态；`refresh` 仅执行读取请求。
- `modmind_select_quota_model`：按 exact ID 选择模型，共用 UI 的选路与验证服务。`billing` 默认为 `quota`；选择免费版时提供 `billing:"free"`，可同时提供目录返回的 `account`。属于账号范围写入，会改变之后的模型消费，必须依据用户意图；经过现有审批，灵感台只读会话禁止调用。当前项目已切换或额度任务仍在运行时拒绝操作。

两项工具已加入内置 MCP 服务端发现列表、路由与参数校验。调用不暴露凭据。测试从 stdio `tools/list` / `tools/call` 穿过实际 bridge 到切换业务服务，再回读型号和线路；同时检查无效参数、审批拒绝、只读和项目变更边界。
