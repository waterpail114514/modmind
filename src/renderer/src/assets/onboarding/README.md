# 茉可新手教程立绘

`moko-poses.png` 为用户提供的正式三姿态立绘去底版本，随应用打包，仅在教程按需加载。没有使用 `output/tutorial-mascot` 中的废弃动作素材。

- PNG 为 1536×1024，保留透明通道，约 1.7 MiB。
- 三列等宽：欢迎、思考、开心。组件以 300% 背景宽度和 0%、50%、100% 横向偏移切换，避免切图与布局变化。
- 使用内置 `image_gen` 的背景提取编辑模式处理用户原图，未使用 CLI。
- 处理提示词要求：只移除白色背景并输出真实透明 PNG；保留原图三个人物的身份、脸、服装、表情、动作、比例与三列位置，不添加背景、文字或其他元素。

消耗此素材的组件为 `components/MokoOnboarding.tsx` 与 `components/moko-onboarding.css`。立绘固定在舞台左侧，平时静止。只有带路、账号成功回应、项目创建成功三个对白节点轻跳一次（420ms、最大 4px），开场不跳；表情以透明度切换，减少动态效果时不跳。
